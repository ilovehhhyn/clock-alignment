# Third-party code

`clock_alignment/_vendor/characters.py` and `clock_alignment/_vendor/state.py` are
copied from [Dwarkesh Patel's ClocktowerBench engine](https://github.com/dwarkeshsp/clocktower)
at commit `c5d9696b42212f4bd4a99c0b5de831fa0643110b`.

Their MIT copyright and permission notice is preserved in
[`clock_alignment/_vendor/LICENSE`](clock_alignment/_vendor/LICENSE) and included
in built distributions. The curated script and dynamic-delegate rules are defined
in this repository's separate engine and rules modules.

No game artwork, branding assets, recorded conversations, or model outputs were
copied into this repository. This project implements a modified research game;
it is not an official Blood on the Clocktower release.
